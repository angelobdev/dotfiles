# Fedora night wallpaper

`desktop-night.jpg` derives from `/usr/share/backgrounds/f44/default/f44-01-night.jxl`, supplied by Fedora's `f44-backgrounds-base` package.

Author: Fedora Design Team. License: Creative Commons Attribution-ShareAlike 4.0 International, included in `LICENSE`.

Modification: converted JPEG XL to JPEG (quality 92), with no visual edits, for compatibility with the installed hyprpaper build.

Source project: https://fedoraproject.org/wiki/Design
License: https://creativecommons.org/licenses/by-sa/4.0/

The installed package's Attribution file labels the default artwork "Fedora 43 Default" despite being shipped under the Fedora 44 path. Its original attribution is preserved in `FEDORA-ATTRIBUTION`.
